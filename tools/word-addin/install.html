Word Add-in

Instantly look up and cite 963,000+ Swiss court decisions and federal statutes directly in Word. Currently in beta testing — your feedback helps shape the final product.

Download Add-in Manifest

Word Online

1
Open Word Online (word.new)
2
Insert → Office Add-ins → My Add-ins → Upload My Add-in
3
Select the downloaded OpenCaseLaw.xml file
4
The OpenCaseLaw panel appears on the right. Start typing a reference.

Word for Mac (persistent)

1
Open Finder. Press Cmd+Shift+G and go to:
~/Library/Containers/com.microsoft.Word/Data/Documents/wef
2
Copy OpenCaseLaw.xml into this folder
3
Restart Word. The add-in loads automatically and persists across sessions.

Word for Windows (persistent)

1
Open File Explorer. Navigate to:
%APPDATA%\Microsoft\Word\STARTUP\wef
(Create the wef folder if it doesn't exist)
2
Copy OpenCaseLaw.xml into this folder
3
Restart Word. The add-in loads automatically and persists across sessions.
This is a beta version pending Microsoft AppSource review. The Desktop sideloading methods (Mac/Windows) are persistent — the add-in stays installed across Word sessions. Word Online requires re-upload each session. Once approved on AppSource, installation will be a single click.
