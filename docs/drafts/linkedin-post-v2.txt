OpenCaseLaw.ch

OpenCaseLaw publishes 965,000 Swiss court decisions from every federal court and all 26 cantons, dating back to 1875. Alongside them: the full text of every federal and cantonal law in three languages, a citation graph of 8.8 million links between decisions, the legislative history of 2,500 federal laws, and scholarly commentary from OnlineKommentar.ch. For the Bundesverfassung, that includes the structured Botschaft digest and the original 1998 parliamentary debate transcripts from both chambers.

The project started in mid-February 2026. The data is CC0. The code is MIT. Updated daily.

Around 1,000 people have used the platform so far — through Claude, ChatGPT, Cursor, Gemini, Grok, a Word add-in, or direct API calls. Traffic patterns suggest it is also being integrated into larger platforms that don't disclose the source.

Practitioners and judges search case law, trace citation chains, and verify whether a precedent still holds. The case brief tool returns the regeste, key reasoning paragraphs, cited statutes, and authority ranking. Looking up a statute also returns the Botschaft that proposed it — the "what" and the "why" in a single call.

Researchers use the citation graph for quantitative legal analysis — tracking how courts read a provision over decades, or mapping which cantonal courts follow which Bundesgericht rulings. The full dataset is on HuggingFace.

Students look up doctrine, read scholarly commentary from OnlineKommentar.ch, and practice with exam questions generated from real Bundesgericht fact patterns.

Anyone can search in plain language. The platform translates everyday terms to legal vocabulary: searching "Vaterschaftsurlaub" finds the statute article even though the law calls it "Urlaub des andern Elternteils." Searching for dog-leash rules in Geneva returns the right article in French, from a German query.

23 research tools at mcp.opencaselaw.ch — works with any MCP client. For Grok and other function-calling LLMs, OpenAI-compatible tool definitions are at the repo. The Word add-in puts the same tools inside the document. No API key. No sign-up.

The platform sets no cookies, creates no user accounts, and never logs what anyone searches. The analytics code is open source.
