Comment ça marche

Installer

Microsoft AppSource → « Get it now ». Gratuit, sans compte, sans carte de crédit. Fonctionne dans Word pour Windows, macOS et Web.

Ouvrir

Word → onglet « Insertion » → « Compléments » → OpenCaseLaw. Le volet Office apparaît à droite du document.

Rechercher

Mot-clé, référence ATF ou numéro de dossier dans le champ de recherche. Liste de résultats live avec nom de juridiction, date, extrait du regeste, nombre de citations.

Insérer

Cliquer sur une carte ou flèches + Entrée — la citation s'insère exactement à l'emplacement du curseur dans la langue choisie. Confirmation par toast.

FAQ

Quelles langues l'add-in prend-il en charge ?

L'interface est livrée en DE, FR, IT et EN — auto-détectée depuis le locale Office, modifiable manuellement. La recherche, les formats de citation et les abréviations légales suivent la convention suisse par langue (DE « Abs. », FR « al. », IT « cpv. »).

Confidentialité — mes requêtes sont-elles enregistrées ?

Non. Nous ne loguons ni le contenu de votre document ni des requêtes personnalisées. Seulement de la télémétrie agrégée, différentiellement privée, si vous y avez consenti. Entièrement documenté dans la déclaration de confidentialité.

Puis-je résilier Pro à tout moment ?

Oui, entièrement via le portail Stripe Billing. Aucun délai de résiliation. Les fonctions Free restent inchangées.

Fonctionne-t-il aussi dans Word pour Mac et Word Web ?

Oui. Office.js fonctionne dans Word Win, Mac et Web (Microsoft 365). L'add-in nécessite une connexion internet vers la base de données live (mcp.opencaselaw.ch).

Existe-t-il une variante self-hosted ?

Oui — l'ensemble du corpus est sur Hugging Face sous CC-BY-4.0, et le code du serveur MCP est sous licence MIT sur GitHub. Les études disposant de leur propre infrastructure peuvent exécuter la pile complète localement.

À quel point les données sont-elles à jour ?

Tribunal fédéral (TF) : généralement dans les 15 minutes suivant la publication sur le Document Service. Toutes les autres sources : quotidiennement via le nightly publish (03:30 UTC). Statut live sur opencaselaw.ch/quality.html.

Qu'est-ce qu'OpenCaseLaw ?

OpenCaseLaw est une infrastructure ouverte pour la jurisprudence suisse — 971'000 décisions de 108 juridictions, 6,5 M d'arêtes de citation, 29 outils MCP, framework qualité 4 couches. L'add-in Word est l'une des nombreuses interfaces ; voir aussi la configuration MCP pour Claude.ai/ChatGPT/Gemini et le papier de recherche.
