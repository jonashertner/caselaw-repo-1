Rechercher

Recherche plein texte sur 972'000+ décisions, directement depuis votre flux de rédaction. Booléen, regeste, numéro de dossier, référence ATF, recherche d'articles. La langue du résultat suit la langue d'origine de la décision (DE/FR/IT).

📋

Citer

Citations correctement formatées en DE/FR/IT/EN — Tribunal fédéral, TAF, TPF, toutes les juridictions cantonales. Pinpoint sur un considérant possible. Un clic insère le texte standard à l'emplacement du curseur.

🛡️

Audit

Audit de clôture 5-rails sur tout le document : chaque citation contrôlée pour existence, pinpoint, juridiction et résolution des renvois normatifs. Numéros ATF inventés et pinpoints inexacts sont reportés sous forme de commentaires Word. Purement déterministe sur la base locale — gratuit.

Outils Pro (IA)

Quatre fonctions assistées par IA — limite quotidienne commune 25 appels/jour, caviardage PII structurel avant tout envoi serveur (EMAIL · AVS · IBAN · IDE · TÉL · DOB · adresse · nom), multilingue DE/FR/IT/EN. CHF 5/mois via Stripe.

✓

Vérifier

Une référence à une décision dans le paragraphe est vérifiée contre le texte intégral de la décision citée. Claude Sonnet 4.6 examine : la source soutient-elle vraiment ce que le paragraphe affirme ? Réponse : oui / partiellement / non — avec motifs.

🛠️

Renforcer

Tout le paragraphe est radiographié : citations vérifiées, jusqu'à 5 arrêts de principe non encore cités proposés (classés par centralité dans le graphe de citations), extraits de doctrine pertinents. Pas d'appel LLM — structurel et rapide (~300 ms).

🔎

Fondement

Marquer une affirmation sans source — Sonnet la parse en demande + indices normatifs, génère des requêtes de recherche et note chaque résultat de 0 à 100 selon la qualité du soutien. Arrêts de principe et ATF priorisés.

📚

Miroir

Refléter tout le document à travers la littérature : Sonnet identifie le problème juridique central, tire un parallèle du canon mondial (Shakespeare, Dürrenmatt, Frisch, Kafka, Sophocle…) et livre 200–400 mots Markdown plus une question de réflexion. Explicitement pas un conseil juridique.

Comment ça marche

Installer

Microsoft AppSource → « Get it now ». Gratuit, sans compte, sans carte de crédit. Fonctionne dans Word pour Windows, macOS et Web.

Ouvrir

Word → onglet « Insertion » → « Compléments » → OpenCaseLaw. Le volet Office apparaît à droite du document.

Mot-clé, référence ATF ou numéro de dossier dans le champ de recherche. Liste de résultats live avec nom de juridiction, date, extrait du regeste, nombre de citations.

Insérer

Cliquer sur une carte ou flèches + Entrée — la citation s'insère exactement à l'emplacement du curseur dans la langue choisie. Confirmation par toast.

FAQ

Quelles langues l'add-in prend-il en charge ?

L'interface est livrée en DE, FR, IT et EN — auto-détectée depuis le locale Office, modifiable manuellement. La recherche, les formats de citation et les abréviations légales suivent la convention suisse par langue (DE « Abs. », FR « al. », IT « cpv. »).

Confidentialité — mes requêtes sont-elles enregistrées ?

Non. Nous ne loguons ni le contenu de votre document ni des requêtes personnalisées. Seulement de la télémétrie agrégée, différentiellement privée, si vous y avez consenti. Entièrement documenté dans la déclaration de confidentialité.

Puis-je résilier Pro à tout moment ?

Oui, entièrement via le portail Stripe Billing. Aucun délai de résiliation. Les fonctions Free restent inchangées.

Fonctionne-t-il aussi dans Word pour Mac et Word Web ?

Oui. Office.js fonctionne dans Word Win, Mac et Web (Microsoft 365). L'add-in nécessite une connexion internet vers la base de données live (mcp.opencaselaw.ch).

Existe-t-il une variante self-hosted ?

Oui — l'ensemble du corpus est sur Hugging Face sous CC0, et le code du serveur MCP est sous licence MIT sur GitHub. Les études disposant de leur propre infrastructure peuvent exécuter la pile complète localement.

À quel point les données sont-elles à jour ?

Tribunal fédéral (TF) : généralement dans les 15 minutes suivant la publication sur le Document Service. Toutes les autres sources : quotidiennement via le nightly publish (03:30 UTC). Statut live sur opencaselaw.ch/quality.html.

Qu'est-ce qu'OpenCaseLaw ?

OpenCaseLaw est une infrastructure ouverte pour la jurisprudence suisse — 972'000+ décisions de 108 juridictions, 8,1 M d'arêtes de citation résolues, 33 outils MCP publics (35 locaux), framework qualité 4 couches. L'add-in Word est l'une des nombreuses interfaces ; voir aussi la configuration MCP pour Claude.ai/ChatGPT/Gemini et le papier de recherche.
