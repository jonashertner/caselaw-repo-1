FAQ

Which languages does the add-in support?

The interface ships in DE, FR, IT and EN — auto-detected from the Office locale, switchable manually. Search, citation formats and statute abbreviations follow Swiss convention per language (DE "Abs.", FR "al.", IT "cpv.").

Privacy — are my queries stored?

No. We do not log document contents or personalized queries. Aggregated, differentially-private telemetry only if you opt in. Fully documented in the privacy notice.

Can I cancel Pro at any time?

Yes, fully through the Stripe Billing Portal. No notice period. Free features remain available unchanged.

Does it work in Word for Mac and Word Web?

Yes. Office.js runs in Word for Windows, Mac and the Web (Microsoft 365). The add-in needs an internet connection to the live database (mcp.opencaselaw.ch).

Is there a self-hosted variant?

Yes — the entire corpus is on Hugging Face under CC-BY-4.0, and the MCP server code is MIT-licensed on GitHub. Firms with their own infrastructure can run the full stack locally.

How current is the data?

Federal Supreme Court (BGer): typically within 15 minutes of publication on the Document Service. All other sources: daily via the nightly publish (03:30 UTC). Live status at opencaselaw.ch/quality.html.

What is OpenCaseLaw?

OpenCaseLaw is open infrastructure for Swiss case law — 971,000 decisions across 108 courts, 6.5 million citation edges, 29 MCP tools, a 4-layer quality framework. The Word add-in is one of several surfaces; see also the MCP setup for Claude.ai/ChatGPT/Gemini and the research paper.
