Prüfen

Eine Entscheidreferenz im Absatz wird gegen den Volltext des zitierten Entscheids verifiziert. Claude Sonnet 4.6 prüft: trägt die Quelle, was der Absatz behauptet? Antwort: trägt / teilweise / nicht — mit Begründung.

🛠️

Stärken

Ganzer Absatz wird strukturell geröntgt: alle Citationen verifiziert, bis zu 5 noch-nicht-zitierte Leitentscheide (ranked nach Zitationsgraph-Zentralität), passende Kommentar-Auszüge. Kein LLM-Call — strukturell und schnell (~300 ms).

🔎

Begründung

Eine Aussage ohne Quelle markieren — Sonnet parst sie in Anspruch + Norm-Hinweise, generiert Suchqueries und scort jeden Treffer auf 0–100, wie gut der Entscheid die Aussage stützt. BGE/Leitentscheide werden priorisiert.

📚

Spiegeln

Ganzes Dokument literarisch reflektieren: Sonnet identifiziert das zentrale rechtliche Problem, zieht eine Parallele aus dem Welt-Kanon (Shakespeare, Dürrenmatt, Frisch, Kafka, Sophokles …) und liefert 200–400 Wörter Markdown plus eine Reflexionsfrage. Explizit kein Rechtsrat.

FAQ

Welche Sprachen unterstützt das Add-In?

Die Oberfläche erscheint in DE, FR, IT und EN — automatisch aus der Office-Locale, manuell umstellbar. Suche, Zitierformate und Gesetzes-Abkürzungen folgen Schweizer Konvention pro Sprache (DE „Abs.", FR „al.", IT „cpv.").

Datenschutz — werden meine Suchanfragen gespeichert?

Nein. Wir loggen weder Inhalte Ihres Dokuments noch personalisierte Suchanfragen. Aggregierte, differenziell-private Telemetrie nur, falls Sie zugestimmt haben. Voll dokumentiert in der Datenschutzerklärung.

Kann ich Pro jederzeit kündigen?

Ja, vollständig im Stripe-Billing-Portal. Keine Kündigungsfrist. Free-Funktionen bleiben unverändert verfügbar.

Funktioniert es auch in Word für Mac und Word Web?

Ja. Office.js läuft in Word Win, Mac, Web (Microsoft 365). Das Add-In benötigt eine Internet-Verbindung zur Live-Datenbank (mcp.opencaselaw.ch).

Gibt es eine Self-Hosting-Variante?

Ja — der gesamte Korpus liegt unter CC0 auf Hugging Face, und der MCP-Server-Code ist MIT-lizenziert auf GitHub. Kanzleien mit eigener Infrastruktur können den vollen Stack lokal betreiben.

Wie aktuell sind die Daten?

Bundesgericht (BGer): in der Regel innerhalb von 15 Minuten nach Veröffentlichung im Document Service. Alle anderen Quellen: täglich via nightly publish (03:30 UTC). Live-Status auf opencaselaw.ch/quality.html.

Was ist OpenCaseLaw?

OpenCaseLaw ist eine offene Infrastruktur für Schweizer Rechtsprechung — 972'000+ Entscheide aus 108 Gerichten, 8.1 Mio. aufgelöste Zitations-Edges, 33 öffentliche MCP-Tools (35 lokal), 4-Layer-Qualitäts-Framework. Das Word-Add-In ist eine von mehreren Oberflächen; siehe auch das MCP-Setup für Claude.ai/ChatGPT/Gemini sowie das Forschungs-Paper.
