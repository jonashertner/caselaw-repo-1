**Two leads for that scan, both cheap:**
1. `cite("BGE 105 Ia 349")` returns `decision_date: "1979-01-01"`. The year is
   right, but 01-01 is almost certainly a year-only date padded to day
   precision. `COUNT(*) WHERE court='bge' AND decision_date LIKE '%-01-01'`
   sizes that class in one indexed query and probably explains a large share
   of the "wrong date" reports without any volume arithmetic.
2. The volume-year rule itself (vol. N = year N + 1874, ±1) is now in
   `_bge_volume_year_mismatch` and runs on a citation string — so it can be
   applied to a `decision_id` list without touching `full_text`.

**#50 is narrower than the real problem.** `search_laws("Verjährung unerlaubte
Handlung")` returns Art. 133 IPRG, Art. 142 IPRG and Art. 207 AHVV — not
Art. 60 OR, which *is* the tort limitation provision. The query expands to
`(verjährung OR prescription OR prescrizione) AND unerlaubte AND handlung` and
Art. 60 OR loses because it does not repeat the query's words. So search_laws
ranks articles that *mention* a topic over the article that *governs* it, with
no explicit reference in the query at all. The #50 fix does not touch this;
it needs concept-level ranking (headings, marginal notes, or the citation
graph as a prior). Unfiled.
